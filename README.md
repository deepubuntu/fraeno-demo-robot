# Fraeno onboarding robot

This private ROS 2 project is a clean end-to-end test of Fraeno onboarding.

It runs a small but complete robot system with a sensor driver, controller,
topics, a health service, a movement action, diagnostics, and a transform.
Fraeno must test the system before a dependency update can be merged.

The first test confirms that ordinary pull requests receive a real Fraeno check.
